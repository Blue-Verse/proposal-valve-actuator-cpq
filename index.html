프로젝트 개요

항목내용

핵심 요구사항 분석

  • 사양 입력 인터페이스 — 밸브 사이즈·압력·재질 등 다양한 사양을 단계별로 입력할 수 있는 웹 폼 (제품군별 동적 폼)
  • 제품 모델 자동 선정 — 입력 사양 기반 적합 모델 자동 매칭 로직 (기존 엑셀 데이터 분석·재정리 후 룰 엔진화)
  • 옵션 결정 — 선정된 모델별 호환 옵션 제시 및 선택 기능 (옵션 간 의존·배제 규칙 반영)
  • 자동 견적 산출 — 모델 + 옵션 조합에 따른 최종 금액 실시간 산출 및 견적서 출력
  • 기술 문서 자동 연동 — 선택 모델의 회로도·도면(CAD/PDF)·데이터시트 즉시 조회/다운로드
  • 제품 데이터 관리(어드민) — 수십~수백 종 모델·사양·가격·문서 링크의 체계적 관리 시스템
  • 비기능 요구사항 — 사양→견적까지 빠른 응답 속도, 사양 매칭/금액 산출의 정확성, 제조업 영업 현장에 맞는 직관적 UI/UX
  • 지원 디바이스 — PC Web 우선, MO 반응형 (협의)
  • 디자인 가이드 — enertork.com 브랜드 아이덴티티 유지하며 산업용 제품의 전문성·신뢰성 전달

제안 포인트

1. 엑셀 → 룰 엔진 전환에 강한 도메인 모델링

  • 현재 엑셀에 흩어진 "사양→모델→옵션→가격" 매트릭스를 PostgreSQL 기반 정규화 스키마와 JSONB 사양 속성으로 재설계 — 신규 모델/옵션 추가 시 코드 수정 없이 어드민에서 등록 가능한 구조
  • 옵션 간 호환·배제 규칙(dependency / mutual-exclusion)을 데이터로 표현해 수년간 누적될 신제품에도 확장 가능하도록 설계
  • 기존 내부 프로그램 + 엑셀 자료를 1차 기획 단계에서 정밀 분석해 누락 케이스(예: 사이즈별 분기 가격, 특수 옵션 조합) 사전 식별

2. 산업용 제품 전문성을 살린 UI/UX

  • enertork.com 브랜드 톤(블루 계열 · 산업용 신뢰감)을 유지하면서, 영업 담당자가 고객 응대 중에도 빠르게 사양을 입력할 수 있는 단계형 폼·즉시 미리보기 구조로 디자인
  • 견적서·도면·데이터시트가 한 화면에서 동시 조회/다운로드되는 통합 결과 뷰 — "전화 응대 중 즉시 견적 회신" 시나리오 최적화

3. 정확성 우선의 견적 산출 엔진

  • 모델 선정·견적 금액 산출에 단위 테스트(Jest)를 강제하여 1순위 우선순위인 "산출물 완성도"를 코드 레벨에서 보장
  • 금액 산정 로직은 데이터 기반(룰 + 가격표)으로 분리해, 가격 정책 변경 시 코드 배포 없이 어드민에서 즉시 반영 가능
  • 견적 이력 보존 — 동일 사양에 대해 과거 견적값을 재현할 수 있도록 견적 시점의 가격표 스냅샷을 저장

4. B2B 내부 시스템 운영 최적화

  • 내부용 인증(영업·재무·관리자 역할 분리, RBAC)으로 권한별 화면/기능 제어 — 가격 수정 권한은 관리자에게만 노출
  • 도면·데이터시트는 S3 호환 객체 스토리지에 보관하고 서명 URL 방식으로 다운로드 — 외부 유출 방지와 빠른 접근 양립
  • 운영 가이드·API 문서·DB 스키마 문서를 산출물에 포함해 향후 사내 개발팀이 이어서 고도화 가능하도록 인수인계 체계 마련

PRD (Product Requirements Document)

프로젝트 요구사항을 정의하고 기능 범위를 명확히 합니다.

1. 프로젝트 배경 및 목적

당사(주식회사 에너토크)는 산업용 밸브 및 엑츄에이터 제조사로, 현재 고객 요청 사양에 따른 제품 모델 선정·견적 산출이 수작업으로 이루어지고 있어 시간·인적 비용 부담이 큼. 내부적으로 일부 개발된 프로그램이 있으나 완성형이 아니며, 웹 기반으로 전환하여 영업 응대 속도, 견적 정확성, 사용 편의성을 동시에 확보하는 것이 본 프로젝트의 목적임.

최종 목표는 "사양 입력 → 모델 자동 선정 → 옵션 결정 → 견적 즉시 산출 → 도면·데이터시트 자동 연동"까지 일원화된 사내용 컨피규레이터(CPQ) 웹을 구축하여, 고객 상담·영업 프로세스의 효율을 극대화하고 영업 경쟁력을 강화하는 것임.

3. 기능 요구사항

3.1 사양 입력 및 모델/옵션 자동 선정

  • [필수] 제품군(밸브 / 액츄에이터)별 단계형 사양 입력 폼 — 사이즈, 압력, 재질, 구동 방식, 토크 등
  • [필수] 입력값 유효성 검사 (범위·단위·필수 항목) 및 실시간 피드백
  • [필수] 입력 사양 기반 적합 모델 자동 매칭 (다중 후보 노출 및 우선순위)
  • [필수] 모델별 호환 옵션 자동 제시, 옵션 간 의존·배제 규칙 처리
  • [선택] 사양 조합 저장/불러오기 (영업 담당자별 즐겨찾기)

3.2 자동 견적 산출

  • [필수] 모델 + 옵션에 따른 최종 금액 실시간 계산 (수량 옵션 포함)
  • [필수] 견적서 화면 출력 + PDF 다운로드
  • [필수] 견적 이력 저장 (사양·옵션·당시 가격표 스냅샷 포함)
  • [선택] 견적서 이메일 송부, 견적 만료일 관리

3.3 기술 문서 자동 연동

  • [필수] 선정 모델별 회로도·도면(CAD/PDF)·데이터시트 자동 매핑
  • [필수] 화면 내 PDF 미리보기 + 원본 다운로드 (서명 URL)
  • [선택] 도면 버전 이력 관리, CAD 파일 메타데이터 노출

3.4 제품 데이터 관리(어드민)

  • [필수] 모델·사양·옵션·가격·문서 CRUD (검색, 필터, 페이지네이션)
  • [필수] 모델 선정 룰(사양 → 모델) 관리, 옵션 호환성 매트릭스 관리
  • [필수] 가격표 관리 (기준 단가, 옵션 가산, 할인 정책)
  • [선택] CSV/Excel 일괄 등록·수정 (기존 엑셀 자료 마이그레이션)
  • [선택] 변경 이력(audit log) 조회

3.5 인증 및 권한

  • [필수] 이메일/비밀번호 로그인 (내부 사용자)
  • [필수] 역할 기반 권한 제어 (영업 / 재무 / 제품 관리자 / 시스템 관리자)
  • [선택] SSO 연동 (사내 IdP 사용 시 협의)

4. 비기능 요구사항

항목요구사항
정확성모델 선정/견적 산출 로직에 단위 테스트 강제, 가격표 스냅샷 보존으로 견적 재현 가능
성능사양 입력 → 모델 선정 → 옵션 → 견적 결과까지 P95 응답 1초 이내 (캐시 적용)
사용자 편의성제조업 영업 환경에 맞춘 단계형 입력, 키보드 친화 폼, 즉시 미리보기, 결과 화면에서 도면·견적 동시 확인
보안HTTPS, JWT, RBAC, SQL Injection 방어, 도면 다운로드 서명 URL, 비밀번호 해시 저장
가용성일일 자동 백업(DB + 객체 스토리지), 핵심 기능 헬스체크
확장성수십~수백 종 모델·다양한 사양 조합을 효율적으로 처리하는 정규화 + JSONB 하이브리드 스키마
유지보수성가격·룰 변경을 코드 배포 없이 어드민에서 반영 가능, OpenAPI 자동 문서화

5. 기술 제약사항 및 전제

  • 본 시스템은 사내(내부용) 웹으로, 외부 공개 인덱싱은 차단(robots/IP 화이트리스트 협의)
  • 지원 디바이스: PC Web 우선, 모바일은 반응형으로 대응 (협의 후 확정)
  • 지원 브라우저: Chrome / Edge / Safari 최신 2개 메이저 버전
  • 도면(CAD) 미리보기는 PDF 변환본 기준 — 원본 CAD 파일은 다운로드만 제공 (브라우저 내 CAD 렌더링은 협의)
  • 가격표·룰 데이터는 클라이언트 자료(엑셀) 기반으로 1차 마이그레이션 후, 어드민에서 운영 (사양 매트릭스가 누락된 케이스는 기획 단계에서 협의)
  • 서버 인프라: AWS Seoul 리전 또는 NCP 중 클라이언트 정책에 맞춰 협의 (본 견적은 표준 사양 기준 환경 구축 비용 포함, 호스팅 비용은 별도)

6. 범위 외 사항 (Out of Scope)

  • 고객(외부) 셀프서비스 견적 포털 — 본 프로젝트는 사내용 한정
  • ERP·회계·재고 등 기간계 시스템 양방향 연동 (필요 시 별도 단계)
  • CAD 원본의 브라우저 내 3D/2D 렌더링 (PDF 변환본 미리보기로 대체)
  • 다국어 지원 (한국어 1종 기준, 추후 협의)
  • 모바일 네이티브 앱 (반응형 웹으로 대응)
  • 장기 유지보수 (1개월 무상 하자 보수 이후 별도 계약)
  • 호스팅 비용·도메인·외부 유료 API 사용료
